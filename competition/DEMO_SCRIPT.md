# Demo script

1. Open the dashboard and state the drought-monitoring problem.
2. Open Spectral Lab and run the repository RGB sample.
3. Show the six reconstructed band previews and explain the model boundary.
4. Open Drought Lab and distinguish forecast risk from measured observations.
5. Open Mission Control and select a candidate under battery/storage limits.
6. Show the scenario comparison and belief update.
7. Close with geographic, proxy-label, data, and simulation limitations.

If describing data provenance during the demo, state that NASA POWER is the
primary climate source in the separate research workflow, where its daily
precipitation and temperature build rolling climate predictors and a
future-rainfall drought proxy. The current rolling features include the
matched calendar-day row and require a daily lag for strict intraday-causal
forecasts. Sentinel-2 scene statistics add the
complementary surface signal. The hosted pages show precomputed outputs and do
not query either source live.
