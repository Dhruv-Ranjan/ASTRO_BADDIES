# Demo script

1. Open the dashboard and state the drought-monitoring problem.
2. Open Spectral Lab and run the repository RGB sample.
3. Show the six reconstructed band previews and explain the model boundary.
4. Open Drought Lab and distinguish forecast risk from measured observations.
5. Open Mission Control and select a candidate under battery/storage limits.
6. Show the scenario comparison and belief update.
7. Close with geographic, proxy-label, data, and simulation limitations.
