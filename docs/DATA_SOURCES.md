# Data sources and licenses

The public release contains code, compact metadata, selected result artifacts,
and a small sample image. It does not contain the approximately 1.1 GB tensor
dataset or remote caches.

- Sentinel-2-style spectral inputs and the Bengaluru sample are project
  artifacts described by the accompanying metadata. Verify provider terms
  before redistribution of any raw imagery.
- NASA POWER and related weather/soil references are used by the scientific
  pipeline where recorded in the AURORA outputs. NASA data terms and
  attribution requirements apply.
- Planetary Computer/Sentinel-2 access code is included for reproducibility,
  but downloaded scenes and signed URLs are not bundled.

No claim is made that every project artifact is NASA-owned data. Consult
`AURORA/aurora_publication_results/research_report.md` and the metadata files
before reusing data. Source code is MIT; third-party data keeps its own
license.
